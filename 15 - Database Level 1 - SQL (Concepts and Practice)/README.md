# 15 - Database Level 1 - SQL (Concepts and Practice)

## Course Overview

A practical introduction to **relational database development and SQL** using Microsoft SQL Server.  
The course focused on understanding how data is modeled, stored, related, queried, and maintained, while building a solid foundation in database design and T-SQL.

## What I Learned

- Built a strong foundation in **relational database concepts**, including data integrity, relationships, redundancy, constraints, and the role of DBMS/RDBMS systems.
- Learned how to analyze requirements and translate them into **Entity-Relationship Diagrams (ERD)** and relational schemas.
- Designed database structures using **entities, attributes, relationships, cardinality, participation, and specialization/generalization**.
- Practiced converting conceptual database designs into **relational schemas** suitable for implementation.
- Developed practical SQL skills with **Microsoft SQL Server**, including database and table creation, modification, and management.
- Worked with **CRUD operations** and SQL data manipulation to insert, update, delete, and retrieve data.
- Developed increasingly complex queries using filtering, sorting, aggregation, grouping, conditional logic, subqueries, and set operations.
- Learned how to combine and analyze data across multiple tables using different types of **SQL JOINs**.
- Applied **database constraints** to enforce data integrity and maintain valid relationships between tables.
- Learned how **indexes** improve query performance and the trade-offs they introduce during data modification.
- Implemented **database backup, differential backup, and restore** operations in SQL Server.
- Studied **database normalization** to reduce redundancy and improve data consistency through 1NF, 2NF, 3NF, BCNF, 4NF, and 5NF.

## Practical Experience

The course included hands-on work with SQL Server databases, where I created and modified database structures, manipulated and queried data, designed relational models, worked with constraints and relationships, performed database backups and restoration, and applied indexing and normalization concepts.
