# C# – Level 1

## Course Overview

This course provides a foundational introduction to **C# and the .NET ecosystem**, progressing from .NET architecture and runtime concepts to core C# programming and Windows Forms desktop application development.

The course combines theoretical concepts with practical exercises and small desktop applications to establish a solid foundation for further C# and .NET development.

## .NET Fundamentals

- Understanding the differences between **Library, Framework, and Platform**.
- Introduction to **.NET**, its ecosystem, and the role of .NET Core and .NET Framework.
- Understanding the **.NET compilation and execution process**.
- Studying the **.NET Framework architecture** and the role of the **CLR (Common Language Runtime)**.
- Understanding key CLR components and concepts including:
  - **CTS (Common Type System)**
  - **CLS (Common Language Specification)**
  - **Garbage Collection**
  - **JIT Compilation**
  - **Assemblies and Metadata**
  - **Managed and Unmanaged Code**
  - **.NET Framework Class Library (FCL)**

## C# Fundamentals

- C# environment setup and basic program structure.
- Core C# syntax and comparison with C++ syntax.
- Variables, data types, and type conversion.
- Strings, interpolation, and formatted output.
- Date and time handling using `DateTime` and `TimeSpan`.
- Operators and expressions.
- Conditional statements and loops.
- Arrays and basic `System.Linq` operations.
- Methods, parameters, return values, named arguments, and method overloading.
- Basic exception handling.
- Working with utility classes such as `Math` and `Random`.

## Windows Forms

Introduction to **Windows Forms** and event-driven desktop application development.

Covered the use of common Windows Forms components for:

- User input and data entry.
- Selection and option controls.
- Forms and navigation.
- Dialogs and file system interaction.
- Menus and context menus.
- Data presentation and validation.
- Timers, notifications, and progress indicators.
- Basic drawing and UI organization using containers.

## Practical Projects

### Pizza Application

Implemented a small Windows Forms application based on defined requirements, applying controls, user input, and event-driven programming.

### Tic-Tac-Toe

Developed a Windows Forms Tic-Tac-Toe application covering basic game logic, UI interaction, and event handling.

## Technical Skills Developed

- C# programming fundamentals.
- .NET and .NET Framework architecture.
- CLR, CTS, CLS, JIT, and Garbage Collection concepts.
- Type systems and type conversion.
- Control flow and data structures.
- Methods and exception handling.
- Windows Forms and event-driven programming.
- Desktop UI development and user input handling.
